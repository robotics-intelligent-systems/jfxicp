# Framework for the Interoperability of Cloud Platforms

EiffelStudio brings new support for the .NETCore solutions. The Eiffel Web Framework (EWF) provides Eiffel users with a layer to build anything on top of the http protocol such as websites, web API/services. The Eiffel2Java interface allows you to call Java routines or attributes from your Eiffel code. Rumoca is a modern Modelica compiler and symbolic interoperability platform written in Rust. Spring Cloud Stream is a framework for building message-driven microservice applications. Spring HATEOAS. The Spring AI project provides a Spring-friendly API and abstractions for developing AI applications. Spring Cloud Kubernetes. Harvester is a modern, open, interoperable, hyperconverged infrastructure (HCI) solution built on Kubernetes. CMAK is a tool for managing Apache Kafka clusters. PeachPie is an open-source PHP compiler designed to run PHP code on the .NET and .NET Core platforms. IronPython is an open-source implementation of Python that integrates with .NET. Node API for .NET is an advanced interoperability between .NET and JavaScript in the same process. Haxe is an open-source, high-level programming language and toolkit designed for cross-platform development. .NEXT (dotNext) is a set of powerful libraries designed for high-performance scenarios. Orleans is a cross-platform framework for building robust, scalable distributed applications. Babelfish for PostgreSQL provides the capability for PostgreSQL to work with applications written for Microsoft SQL Server. IKVM is an implementation of Java for the Microsoft .NET platform.  Espresso is an implementation of the Java Virtual Machine (JVM) that runs on the Truffle framework as part of GraalVM. Quarkus is a Cloud Native, Container First framework. Rascal meta-programming language. OpenWhisk is a serverless functions platform for building cloud applications. Delta Lake is an open-source storage framework that enables building a Lakehouse architecture. MinIO is a high-performance, S3 compatible object store. 

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
