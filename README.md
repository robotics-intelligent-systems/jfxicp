# Framework for the Interoperability of Cloud Platforms

jank is a Clojure dialect on LLVM with C++ interop. Clara is a forward-chaining rules engine written in Clojure (Script) with Java interoperability. Dagster is a cloud-native data pipeline orchestrator. Spring Cloud Stream is a framework for building message-driven microservice applications. Spring HATEOAS. Spring Cloud Kubernetes. Harvester is a modern, open, interoperable, hyperconverged infrastructure (HCI) solution built on Kubernetes. CMAK is a tool for managing Apache Kafka clusters. Argo Workflows is an open source container-native workflow engine for orchestrating parallel jobs on Kubernetes. PeachPie is an open-source PHP compiler designed to run PHP code on the .NET and .NET Core platforms. IronPython is an open-source implementation of Python that integrates with .NET. Node API for .NET is an advanced interoperability between .NET and JavaScript in the same process. Haxe is an open-source, high-level programming language and toolkit designed for cross-platform development. .NEXT (dotNext) is a set of powerful libraries designed for high-performance scenarios. ONNX Runtime is a cross-platform inference and training machine-learning accelerator. Orleans is a cross-platform framework for building robust, scalable distributed applications. Babelfish for PostgreSQL provides the capability for PostgreSQL to work with applications written for Microsoft SQL Server. IKVM is an implementation of Java for the Microsoft .NET platform.  Cover: a safe subset of C++ on the JVM using Graal/Truffle. Quarkus is a Cloud Native, Container First framework. Rascal meta-programming language. A# is a port of the Ada programming language to the Microsoft .NET platform. OpenWhisk is a serverless functions platform for building cloud applications. Delta Lake is an open-source storage framework that enables building a Lakehouse architecture. MinIO is a high-performance, S3 compatible object store.   

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
